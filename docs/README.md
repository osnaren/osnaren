# Documentation

Public context for the portfolio lives here so the repository root stays focused on the GitHub profile experience.

- [Portfolio brief](portfolio-brief.md): audience, design principles, accessibility, and performance goals.
- [Live portfolio](https://osnaren.com): the complete interactive experience.
- [Resume](https://osnaren.com/resume): web and print-friendly professional history.

Vercel Web Analytics is mounted once in the root layout and records page views across client-side navigation. The analytics component removes URL query strings and fragments before sending events. Web Analytics must be enabled in the Vercel project before deployment; verify it by checking for a successful `view` request in the browser's Network tab.
